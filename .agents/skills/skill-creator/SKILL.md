# Skill: Skill Creator (스킬 제작 및 자가 진화)

## 목적
유저와 협업하며 발생한 반복 작업, 피드백, 해결된 문제점(이슈)을 표준화된 스킬로 구조화하여 AI 하네스가 **스스로 학습하고 성장**하도록 만듭니다.

## 스킬 생성 5단계 프로세스

1. **학습 트리거 식별**:
   - 유저가 동일한 피드백을 2회 이상 준 경우 (예: "폰트 크기는 clamp로 해줘", "토큰은 design.ts 참조해")
   - 복잡한 다단계 작업(예: 새 프로젝트 케이스 추가, 다크모드 대응 등)이 완료된 후
   - 유저가 직접 "이 워크플로우를 스킬로 저장해줘" 요청할 때

2. **스킬 디렉토리 구조 생성**:
   ```
   .agents/skills/<skill-name>/
   ├── SKILL.md          # YAML frontmatter + 상세 가이드 (필수)
   ├── references/       # 템플릿, 코드 조각, 토큰 (선택)
   └── evals/            # eval-log.md (학습 및 개선 이력 기록)
   ```

3. **SKILL.md 표준 템플릿 작성**:
   ```markdown
   ---
   name: <영문-kebab-case>
   description: >-
     이 스킬이 해결하는 문제와 활성화되는 시점을 2~3줄로 명확히 작성.
   ---

   # Skill: <이름>

   ## 목적
   ...

   ## 실행 단계
   1. ...
   2. ...

   ## 체크리스트 & 주의사항
   - [ ] ...
   ```

4. **검증 및 evals 기록**:
   - 새로 작성된 스킬의 유효성 검사 (YAML 문법, 파일 경로, 룰 충돌 여부)
   - `evals/eval-log.md`에 생성 배경 및 테스트 결과 기록

5. **하네스 레지스트리(AGENTS.md, CLAUDE.md) 자동 업데이트**:
   - `AGENTS.md`의 스킬 목록과 작업 매핑 테이블에 새 스킬 등록
