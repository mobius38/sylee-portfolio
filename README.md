## 🎯 Key Design Competencies (핵심 역량)

- **UX Architecture & Systems Thinking**: 
  - 복잡한 대용량 트랜잭션, 다자간 권한 체계, 파편화된 멀티 프로덕트를 단일한 사용자 맥락으로 통합
- **Interactive Hi-Fi Prototyping**: 
  - 엔터프라이즈 B2B 수주 및 비즈니스 검증을 위한 실제 서비스 수준의 인터랙티브 프로토타이핑
- **Design System & Governance**: 
  - Figma Variables 기반 디자인 토큰(Foundations) 및 재사용 가능한 UI 컴포넌트(Components 26종) 설계 및 개발 동기화
- **End-to-End Ownership**: 
  - 브랜드 아이덴티티(BI) 수립부터 제품 UX/UI, 디자인 QA, 서비스 런칭 및 운영 성장(14배 트래픽 달성)까지 주도

## 🛠️ Tech & Design Stack

### Design Tools & Methodology
- **Figma**: Variables, Design Tokens, Auto Layout, Component Anatomy, Interactive Prototyping
- **Design Governance**: Design QA, Token-to-Code Mapping, Design Guidelines
- **Visual & Brand**: Adobe Illustrator, Photoshop, 3D Mockup Visual Direction

### Engineering & Implementation (Web Portfolio)
- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Performance**: WebP/Responsive Media, A11y Semantic Structure, 60fps Micro-interactions
- **Hosting**: Vercel Git Continuous Deployment
